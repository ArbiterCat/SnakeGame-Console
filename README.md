# SnakeGame

Консольная «Змейка» на C#. Собирай еду, чтобы расти. Через край поля змейка выходит с противоположной стороны. Столкновение с телом заканчивает раунд, а заполненное поле означает победу.

## Запуск

Установи .NET 8 SDK, открой терминал в корне репозитория и выполни:

```sh
dotnet run --project src/SnakeGame
```

Для игры нужен интерактивный терминал размером хотя бы 40 столбцов на 24 строки. Сторонних зависимостей у игры нет.

| Клавиши | Действие |
| --- | --- |
| Enter или S | Начать игру в меню |
| Стрелки или WASD | Поворот |
| P | Пауза и продолжение |
| Esc | Вернуться в меню во время игры |
| Q или Esc | Выйти из меню |

## Код и тесты

- `src/SnakeGame/Core` хранит состояние поля и применяет правила движения, роста и столкновений.
- `src/SnakeGame/Terminal` читает клавиши, управляет игровым циклом и рисует поле.
- `tests/SnakeGame.Tests` проверяет правила игры отдельно от терминала.

```sh
dotnet test SnakeGame.sln
```
